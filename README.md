## 🎨 Features & Animations
1. **Light Luxury Aesthetics:** Soft warm ivory, champagne cream, gold foil detailing, and dark espresso typography.
2. **Royal Envelope Wax Seal Opening:** Interactive gate modal with a golden wax seal monogram ("H&L") that plays wedding background music upon opening.
3. **Falling Petals & Stardust Canvas:** Ambient lightweight 60fps petal shower.
4. **December 2026 Interactive Calendar:** Dynamically generates the calendar grid with an animated heart encircling December 30.
5. **Real-Time Countdown Timer:** Counts down live to 30 December 2026, 12:00 PM IST.
6. **Swipeable Rail:** Touch-enabled horizontal carousel with snap alignment.
7. **Dancing Bride & Groom Animation:** Interactive animated couple performing a waltz, with tap-to-spin and confetti celebration.
8. **1-Click Actions:** Direct Google Maps navigation, address copy, and 1-click Google Calendar event generator.
9. **Floating Vinyl Music Player:** Bottom-corner control with spinning vinyl animation.

## 🚀 Deployment
This website is 100% self-contained and static:
- **Netlify:** Drag and drop the `hanan` folder directly into [Netlify Drop](https://app.netlify.com/drop) to publish it live in seconds.
- **GitHub Pages:** Push the repository to GitHub and enable Pages in repository settings.
- **Vercel:** Import the folder and deploy as a static site.
